# 1. Lab 硬件基线：单张 RTX 4090 / 7B 级量化模型 / ¥500 AutoDL

- **Status（状态）**: Accepted
- **Date（日期）**: 2026-08-11

## Context（背景）

学习者用 AutoDL 云卡练习，预算 ¥500 理想 / ¥1000 上限。整个教程有大量 GPU Lab 与一个 Capstone，需要一个**贯穿全站的硬件/模型基线**，否则每个 Lab 各自选卡选模型，会导致：预算失控、示例数字不一致、新手无法复现。

可选方案：
- **(a) 大模型（70B）+ 多卡 A100**：最真实，但远超预算（单次实验就可能烧掉大半预算），新手也难复现。
- **(b) 中模型（13–34B）+ 单卡 A100/多卡**：折中，但仍偏贵，24G 单卡跑不动 FP16。
- **(c) 7B 级 + 量化 + 单张 4090(24G)**：便宜、可复现，覆盖绝大多数推理优化知识点。

## Decision（决策）

所有 Lab 与 Capstone **默认锁定：单张 RTX 4090(24G) + 7B 级模型 + 量化**。**主线基线模型 = `Qwen2.5-7B-Instruct`**（中英俱强、AutoDL 下载快、AWQ/GPTQ 量化件齐全）；在少数英文生态示例更标准的场景（如某些量化 / speculative-decoding 论文复现）**附带 `Llama-3.1-8B-Instruct` 作交叉引用**。仅 1–2 个必须的多卡 / 大模型专题（如 TP/PP 演示）改用 A100 并「开机即关」。所有非计算工作（装环境、下模型、写代码、调试）一律用 AutoDL **无卡模式**，GPU 计费只在真跑实验时开。

## Consequences（后果）

**正面：**
- 预算可控：¥500 ≈ ~250 张 4090-时，足够跑完全部主线 Lab 且有余量。
- 示例统一、数字一致，新手能一比一复现。
- 覆盖 ~90% 推理优化知识点——KV cache、量化、continuous batching、PagedAttention、prefix caching、speculative decoding 在 7B 单卡上都能演示并量化。

**权衡 / 负面：**
- Tensor/Pipeline parallelism 只能小规模演示，无法体验真实大集群规模。
- 70B 级特有现象（极端显存压力、跨卡通信瓶颈）只能「精算 + 小样」近似，超大规模生产直觉需另行补足。

**可逆性：** 模型与卡是配置项，日后预算放宽可上调；但所有 Lab 文案与吞吐/显存数字都围绕此基线计算，改动需整体重算，故立此 ADR 记录基线。
