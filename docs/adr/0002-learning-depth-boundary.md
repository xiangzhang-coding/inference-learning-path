# 2. 学习深度边界：读懂 + 会调 + 应用层，不手写 CUDA C++

- **Status（状态）**: Accepted
- **Date（日期）**: 2026-08-11

## Context（背景）

北极星是「大厂 LLM 推理 Infra 岗 + 拉满吞吐」。学习者强于 PyTorch，弱于 GPU 编程与并行编程。往栈的多深处走，有三种取向：
- **(A) 读懂 + 会调 + 写少量 Triton**：能推理 kernel 为何快、建立显存/带宽/调度心智模型、会写简单 Triton、能读 vLLM 的 CUDA/Triton 源码。
- **(B) 手写高性能 CUDA C++**：系统学 CUDA、自己写并优化 kernel——一条很长的、相对独立的路径。
- **(C) 纯应用层黑盒**：只会配置与调参，不理解底层。

## Decision（决策）

深度边界锁在 **A + C**：既要能推理底层为何快、会调优、能读源码（A），也要打通到应用层部署与调参（C）。**手写并优化 CUDA C++（B）明确进 Backlog**，不在主线课程。Triton 只学到「会写几个简单 kernel + 能读 PagedAttention kernel」。

## Consequences（后果）

**正面：**
- 投入产出比最高，且正好匹配大厂推理岗真实考察层次：理解原理 + 调优 + 源码阅读，而非手写 kernel 竞赛。
- 新手不会淹死在 CUDA 细节里，动机先行的排课得以成立。

**权衡 / 负面：**
- 学习者不会具备从零写 SOTA kernel 的能力；若职业方向转向「kernel 工程师 / 编译器」，需回补 Backlog 中的 CUDA C++ 模块。

**可逆性：** 中等。课程日后可追加 CUDA C++ 模块，但主线的**深度校准**（每节的讲解详略、Lab 难度、面试题深度）都围绕此边界设计，故立此 ADR 记录。
